# ایده AI - چت هوش مصنوعی پیشرفته

![ایده AI](./assets/screenshots/preview.png)

یک رابط کاربری مدرن و واکنش‌گرا برای چت با هوش مصنوعی - کاملاً کلاینت‌ساید

## ✨ ویژگی‌ها
- 🎯 **پشتیبانی کامل فارسی** - رابط راست‌چین و پیام‌های فارسی
- 🎨 **تم‌های متنوع** - تیره، روشن، آبی، سبز، بنفش
- 📱 **طراحی واکنش‌گرا** - سازگار با موبایل و دسکتاپ
- 🤖 **مدل‌های چندگانه** - ایده، GPT-4، Claude، Gemini، LLaMA
- 🎭 **مدال آموزشی** - قابلیت آپلود دیتاست و آموزش مدل
- 💾 **ذخیره‌سازی محلی** - تنظیمات در localStorage ذخیره می‌شوند

## 🚀 شروع سریع

```bash
# کلون کردن پروژه
git clone https://github.com/your-username/idea-ai-chat.git

# رفتن به دایرکتوری پروژه
cd idea-ai-chat

# راه‌اندازی سرور توسعه
make dev
```

## 📦 دستورات پروژه

```bash
make help        # مشاهده تمام دستورات
make setup       # راه‌اندازی اولیه
make dev         # اجرای سرور توسعه
make deploy      # استقرار روی GitHub Pages
make docker-up   # اجرا با Docker
```

## 🌐 استقرار

### GitHub Pages
1. ریپازیتوری را در GitHub ایجاد کنید
2. به Settings > Pages بروید
3. Branch: `main`، Folder: `/ (root)` انتخاب کنید
4. بعد از چند دقیقه در `https://username.github.io/idea-ai-chat  ` قابل دسترسی است

### استقرار دستی
فایل `index.html` را در هر هاست استاتیکی آپلود کنید.

## 🤝 مشارکت
1. پروژه را Fork کنید
2. Branch جدید ایجاد کنید: `git checkout -b feature/amazing-feature`
3. تغییرات را Commit کنید: `git commit -m 'Add amazing feature'`
4. به Branch اصلی Push کنید: `git push origin feature/amazing-feature`
5. Pull Request ایجاد کنید
